🍪 CookieVerse Eternal Ceremony — The Eternal Legends Edition

Project Mission

Build a polished, fully interactive, mobile-friendly CookieVerse Eternal Ceremony fan website using Python Flask, HTML, CSS, and JavaScript.

The ceremony celebrates Cookie Run games, legendary characters, memorable updates, and the worldwide Cookie Runners community.

Tagline: “One CookieVerse. Many legends. One unforgettable celebration.”

✨ Design and Visual Identity

Create a premium, magical awards-night experience.

- Theme: Midnight blue, deep violet, cream, and royal gold.
- Background: Animated stars, floating sparkles, subtle glowing particles, and elegant gradients.
- Typography: Clear, elegant headings and readable body text.
- Award cards: Gold borders, glass-like surfaces, soft shadows, and smooth hover effects.
- Hero section: Large ceremony title, tagline, and a prominent celebration button.
- Winner cards: Award title, winner name, a short tribute, and a distinctive medal or trophy.
- Anniversary section: A special golden tribute to OvenBreak's tenth anniversary.
- Footer: Community dedication and fan-project disclaimer.

Use original CSS illustrations, icons, and effects or appropriately licensed assets. Do not assume copyrighted character artwork is available locally.

🎬 Interactive Ceremony

Implement a fully working ceremony flow.

1. Display a welcome screen with a Begin the Eternal Ceremony button.

2. When tapped, start the ceremony and reveal the winners one award at a time.

3. Animate each award title before revealing its winner.

4. Add golden sparkles, confetti, glowing borders, and smooth transitions.

5. Provide working Next Award and Previous Award controls.

6. Show ceremony progress, such as “Award 2 of 10.”

7. Add a working Skip to Finale button.

8. At the finale, display all major winners and the message:
   
   “Every Cookie has a story. Every game leaves a legacy. Every Cookie Runner belongs.”

9. Add a working Replay Ceremony button.

10. Include a Copy Ceremony Summary button that copies the winners and award categories.

11. Ensure all buttons work on Android mobile browsers as well as desktop browsers.

Do not create decorative buttons that do nothing. Test every interaction.

🛠️ Technical Requirements

- Backend: Python Flask.
- Frontend: HTML5, CSS3, and vanilla JavaScript.
- Mobile-first responsive layout.
- Must run in Termux on Android and in Ubuntu.
- Use a clean project structure with templates and static assets.
- Include "app.py" and "requirements.txt".
- Use Flask routes correctly and keep frontend assets organized.
- No paid APIs, API keys, or mandatory external services.
- The core ceremony must work without a database.
- Keep JavaScript separate from HTML where practical.
- Add error handling and avoid broken links or missing assets.
- Include accessible labels, keyboard navigation, visible focus indicators, and reduced-motion support.
- Use the Asia/Kolkata timezone only if displaying a live date or time.
- Do not invent official awards, endorsements, or unverified game announcements.

📱 Mobile Compatibility

Prioritize Android phones and tablets.

- Buttons must be easy to tap.
- Award cards must fit narrow screens.
- Avoid horizontal overflow.
- Make animations smooth without excessive CPU usage.
- Ensure the celebration button works with touch input.
- Verify that the layout remains usable in portrait and landscape modes.

🧪 Testing Checklist

Before declaring the project complete:

- Run the Flask app and verify that the home page loads.
- Test the ceremony start button.
- Test Next Award, Previous Award, Skip to Finale, and Replay.
- Verify every winner and award category.
- Test the copy-summary functionality.
- Check responsive behavior on mobile-sized screens.
- Check reduced-motion behavior.
- Verify that no buttons are inert and no JavaScript errors prevent the ceremony from working.
