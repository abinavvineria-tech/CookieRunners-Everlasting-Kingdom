EVERLASTING BLOOM — Project Documentation
==========================================

Purpose
-------
A respectful, unofficial fan tribute to White Lily Cookie (Cookie Run: Kingdom), celebrating her friendship with Pure Vanilla Cookie and the values of kindness, friendship, respect, courage, and hope.

Pages
-----
1. Home (/) — Introduction, principles
2. Her Legend (/legend) — Verified milestones
3. PureLily Chronicles (/chronicles) — Their friendship
4. Timeline (/timeline) — 2023-2026, Aug 12 2026 highlighted
5. Everlasting Garden (/garden) — Interactive flower planting
6. Letters of Kindness (/letters) — Moderated messages
7. Memory Archive (/memories) — Verified milestones
8. About (/about) — Credits and unofficial disclaimer

Technical
---------
- Python 3.10+, Flask, SQLite
- Mobile-first responsive CSS with glassmorphism
- Secure admin auth via session
- CLI: bloomctl
- Works on Termux and Ubuntu
