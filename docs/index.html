Installation Guide

These instructions apply to real, verified sub-projects. If a sub-project does not yet include requirements.txt or app.py, treat it as planned or prototype only.

Prerequisites

  • Python 3 (3.9+ recommended)
  • pip (included with Python)
  • git (to clone)
  • A terminal — Termux on Android, or regular terminal on Ubuntu / Linux

Clone

git clone https://github.com/abinavvineria-tech/CookieRunners-Everlasting-Kingdom.git
cd CookieRunners-Everlasting-Kingdom

Virtual Environment

# Ubuntu / Linux
python3 -m venv .venv
source .venv/bin/activate

# Android Termux
python -m venv .venv
source .venv/bin/activate

Dependencies

# From the sub-project folder that has requirements.txt
pip install -r requirements.txt

# Example (Flask ceremony prototype):
# Flask>=3.0,<4.0

Run (verified prototype example)

# From the folder containing app.py
python app.py

# Default: http://127.0.0.1:5000

Note: Do not expose a development server directly to the public internet without production hosting and a security review. Some sub-projects are not yet installable — inspect each folder individually.

Contribution Guide

  • Fork the repository and create a new branch from main.
  • Add or improve documentation, code, assets, or celebration ideas.
  • Test changes on Android/Termux or Ubuntu before submitting.
  • Label clearly anything demo, prototype, or unverified.
  • Open a pull request with a clear description.
  • Be respectful and inclusive. Cookie Runners of all backgrounds are welcome.

Avoid claiming official affiliation with Devsisters. Preserve existing documentation. Do not invent achievements, dates, or endorsements.
