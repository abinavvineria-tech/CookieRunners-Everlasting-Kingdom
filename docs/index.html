01About the Kingdom

Every Cookie Runner has a story. Every repository begins an adventure.

Welcome to Cookie Runners Everlasting Kingdom — an unofficial, community-made fan space celebrating Cookie Run games, characters, anniversaries, and the creativity of Cookie Runners around the world.

This repository is a community-driven home for fan-made projects, Flask websites, Termux tools, Cookie Run timelines, anniversary celebrations, and creative experiments inspired by CRK, OvenBreak, OvenSmash, and more.

Whether you're here for the lore, the celebrations, or the code — you belong in this kitchen.

  • ✦ One community. Many adventures. An everlasting legacy.
  • ✦ Welcoming Cookie Runners of all experience levels.
  • ✦ Documenting Cookie Run milestones and anniversaries.
  • ✦ Hosting small, working fan creations anyone can run and modify.

07Frequently Asked Questions

Common questions about the kingdom.

Is this an official Cookie Run project?

No. Cookie Runners Everlasting Kingdom is an unofficial, community-made fan project. It is not affiliated with, endorsed by, or sponsored by Devsisters Corporation or the official Cookie Run games. All Cookie Run names, characters, artwork, trademarks, and related intellectual property belong to their respective owners.

Can I install and run this?

This repository is currently in a documentation/seed stage. Some folders contain verified prototypes (e.g., CookieVerse_Eternal_Ceremony_Flask, everlink-ssh) with their own README and requirements. Other folders are marked planned or in development and are not yet installable products. Inspect each folder individually.

What platforms are supported?

Android with Termux, Linux/Ubuntu, and other platforms where Python 3.9+ and Flask are supported.

How can I contribute?

Fork the repository, create a new branch from main, add or improve documentation/code/assets, test on Android/Termux or Ubuntu, label prototype or unverified items clearly, and open a pull request with a clear description.

Are there releases?

No releases have been published yet. Check the Updates section for live repository statistics.
